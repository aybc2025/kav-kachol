# קו כחול

אפליקציית PWA בעברית ללימוד חוקי הוקי הקרח: 9 יחידות לימוד על תרשים מגרש שזז צעד אחר צעד,
חידונים, מילון מונחים עברית–אנגלית וסימני שופטים. עובדת אופליין, בלי חשבון ובלי שרת.

## הפעלה מקומית

```bash
npm install
npm run dev
```

## העלאה לאוויר

1. יוצרים ריפו בשם `kav-kachol` ב-GitHub ומעלים אליו את הקוד.
2. ב-Settings → Pages בוחרים Source: **GitHub Actions**.
3. כל push ל-`main` בונה ומעלה את האתר אל `https://<user>.github.io/kav-kachol/`.

אם שם הריפו שונה, מעדכנים את `BASE` בקובץ `vite.config.js`.
